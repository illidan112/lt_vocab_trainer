# Литовские слова

Статическое мобильное приложение для изучения литовских слов. Каталог → добавить слово → открыть ответ → назначить повторение. Прогресс хранится в браузере; резервная копия скачивается в JSON.

## Запуск

Из папки проекта выполните `python3 -m http.server 8000`, затем откройте `http://localhost:8000`. На Windows можно использовать `py -m http.server 8000`. Нужен современный браузер. Открытие `index.html` через `file://` не подходит: загрузка JSON и PWA требуют веб-сервера.

`node --test tests/*.test.js` запускает тесты (Node.js 20+). `node scripts/check-assets.js` проверяет словарь и файлы перед публикацией. Зависимости устанавливать не требуется.

## Проверка дат

Откройте `http://localhost:8000/?demo=1&day=1` для условного «завтра» или `?demo=1&day=7` для «через неделю». В этом режиме используется отдельное временное хранилище вкладки, которое не меняет обычный прогресс. Для перехода между датами в рамках той же вкладки меняйте параметр URL. На тестовом хостинге это тоже работает.

## Cloudflare Pages

Подключите GitHub-репозиторий в **Workers & Pages → Create → Pages → Connect to Git**. Production branch: `main`. Framework preset: `None`. Build command: оставить пустым. Build output directory: `/` (корень репозитория; если интерфейс требует значение, используйте `.`). Root directory: `/`. После публикации откройте адрес `*.pages.dev`. Сайт статический, Pages Functions и переменные окружения не используются. HTTPS на адресе Pages поддерживает установку PWA. Храните рабочий прогресс на постоянном адресе, поскольку локальный браузер и preview-домены имеют отдельное хранилище.

## Медиа

20 начальных карточек снабжены наглядными символами; собственные иллюстрации и записанное аудио пока не входят в архив. Для изображения поместите локальный файл в проект и добавьте в слово поле `image`, например `/media/namas.webp`. Для MP3 добавьте `audio`, например `/media/namas.mp3`. Если MP3 нет, кнопка пытается использовать установленный на устройстве литовский голос. Если его нет, приложение сообщает об этом. Для офлайна файлы медиа кэшируются после просмотра или прослушивания; гарантируется офлайн-доступ к интерфейсу и словарю после первой успешной загрузки.

## Резервная копия

Кнопка «Резервная копия» скачивает JSON прогресса и позволяет восстановить его. Хранение браузера может быть очищено пользователем или системой. Сохраняйте копию периодически.

## Ручная проверка на Pixel

1. Откройте адрес Pages в Chrome. Пройдите новые карточки, переводы примеров и навигацию.
2. Добавьте слово дважды: в очереди должен быть один экземпляр.
3. Откройте повторение: ответ скрыт, «Не помню» возвращает слово в конец очереди, интервалы убирают его до срока.
4. Перезагрузите страницу: прогресс на том же адресе сохранился.
5. Скачайте резервную копию, добавьте ещё слово, восстановите копию и проверьте результат.
6. Проверьте голос: он работает, если в системе есть литовский голос; иначе будет сообщение.
7. Добавьте сайт на главный экран, дождитесь первой загрузки, включите авиарежим и откройте приложение снова.
8. После обновления сайта закройте все окна приложения и откройте его снова; проверьте сохранение прогресса.
